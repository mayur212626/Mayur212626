## 🔨 Things I've Built

### 🏥 Clinical Lab Abnormality Predictor
A full end-to-end ML system that predicts diabetes risk from clinical
lab values — not just a notebook, but a real deployed pipeline with a
live API, bias audits, SHAP explanations, and CI/CD.

`PyTorch` `Scikit-learn` `FastAPI` `AWS SageMaker` `Docker` `MLflow` `SHAP`

**AUC-ROC: 0.9618** | 89% accuracy | 92% sensitivity | Zero fairness disparity

🔗 [Live API](https://clinical-lab-predictor.onrender.com) · [Code](https://github.com/mayur212626/clinical-lab-predictor)

---

### 🔍 Large Scale Log Anomaly Detection
500,000+ HTTP server log records. Ensemble of Isolation Forest, LOF,
and a rule engine — 540x critical error lift, Precision@100 of 0.78.
Full drift detection and SHAP explainability included.

`PySpark` `Isolation Forest` `LOF` `MLflow` `FastAPI` `AWS S3`

🔗 [Code](https://github.com/mayur212626/anomaly-detection)

---

### 📈 Stock Price Prediction with LSTM + News Sentiment
LSTM pipeline on AWS SageMaker combining 39 technical indicators with
NLP sentiment from 6,700+ financial news articles. MAPE: 7.19% —
7.1% better than baseline.

`PyTorch` `AWS SageMaker` `NLP` `PySpark`

### 🚢 Ship Type & Course Prediction — AIS Maritime Data
358,000+ real AIS vessel records. COG regression model R²: 0.94,
vessel type deep learning classifier 92% accuracy, AUC: 0.98.
Full PySpark preprocessing and model governance pipeline.

`Scikit-learn` `PySpark` `SQL` `Deep Learning`

🔗 [Code](https://github.com/mayur212626/PREDICTION-OF-SHIP-TYPE-AND-COG-FROM-AIS-DATA-SET)
